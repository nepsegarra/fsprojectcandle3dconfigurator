# 🕯️ Square Gift Store 3D Configurator
**GitHub Link:** [fsprojectcandle3dconfigurator](https://github.com/nepsegarra/fsprojectcandle3dconfigurator.git)

## 📌 Project Overview
A full-stack 3D product customizer built for The Square Gift Store (Auckland). This app allows users to design sacramental candles with real-time 3D previews using Three.js and saves order data to a MySQL backend.

## 🚀 Technical Stack
- **Frontend:** Three.js (WebGL), Bootstrap 5, EJS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** Express-Session

## 🛠️ Setup
1. Clone the repo: `git clone https://github.com/nepsegarra/fsprojectcandle3dconfigurator.git`
2. Install dependencies: `npm install`
3. Configure your `.env` file with MySQL credentials.
4. Run: `node app`
